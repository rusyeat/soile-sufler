# SÓILE — Онлайн суфлер

Қазақша интерфейсі бар, браузерде жұмыс істейтін суфлер. Сервер, тіркелу немесе жинақтау қажет емес.

## Мүмкіндіктер

- Бірқалыпты автоскролл және 10–180 px/с жылдамдық
- Толық экран, айна режимі, оқу сызығы, 3 секунд дайындық
- 24–96 px қаріп, туралау, төрт дайын палитра және еркін түстер
- TXT импорт/экспорт, сөз санау, оқу уақыты және прогресс
- Мәтін мен баптауларды localStorage арқылы құрылғыда сақтау
- Телефон, планшет және компьютерге бейімделген

## Іске қосу

`dist/index.html` файлын браузерде ашыңыз немесе:

```sh
npm start
```

Сосын http://localhost:4173 мекенжайын ашыңыз. Node.js 18+ жеткілікті, сыртқы тәуелділік жоқ.

## Пернелер

Space: бастау/кідірту · ↑/↓: жылдамдық · R: басына · F: толық экран · Esc: экраннан шығу. Редакторда мәтін теріп жатқанда пернелер қалыпты жұмыс істейді.

## GitHub Pages

Сайт: https://rusyeat.github.io/soile-sufler/

GitHub Pages `gh-pages` тармағының түбірінен жарияланады. Негізгі код `main` тармағында, сайт файлдары `dist/` бумасында орналасқан. Өзгерісті commit/push жасағаннан кейін жариялау:

```sh
git subtree push --prefix dist origin gh-pages
```

Settings → Pages бөлімінде **Deploy from a branch → gh-pages → / (root)** таңдалған болуы керек.

## Құпиялық

Сайт мәтінді серверге жібермейді. Мәтін осы браузердің localStorage қоймасында сақталады. TXT экспорт арқылы көшірме сақтаңыз. Толық экран браузер рұқсат берсе қосылады, әйтпесе оқу режимі бүкіл бетке жайылады.
